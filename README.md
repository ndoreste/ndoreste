# Nauzet Doreste

**Administración de sistemas · Automatización con IA · Ciberseguridad en formación**

Estudio **2º de ASIR** y un **Máster en Ciberseguridad** en ThePower Prometeo (Canarias, España).
Monto y documento infraestructura Linux y de red, automatizo procesos con **n8n + LLMs** y construyo herramientas pequeñas en **Node.js**.
Todo lo que aparece aquí es trabajo real, se puede ejecutar o revisar, y se publica sin secretos.

## Proyectos destacados

**[ASIR Knowledge Graph 3D](https://github.com/ndoreste/asir-knowledge-graph-3d)** · [demo](https://ndoreste.github.io/asir-knowledge-graph-3d/)
Grafo 3D interactivo de mis apuntes de ASIR (319 notas, 2.856 enlaces). Parser de wikilinks en Node.js, render 3D escrito a mano en Canvas y un build público que se bloquea si detecta datos privados.
`Node.js` `Canvas 2D` `Playwright` `PowerShell` `Obsidian`

**[ASIR Infra Lab](https://github.com/ndoreste/asir-infra-lab)** · proyecto en equipo
Infraestructura TI de una empresa ficticia (proyecto intermodular de 1º ASIR). Ubuntu Server con DNS (BIND9), Apache con HTTPS, Samba, UFW, fail2ban y backups con cron; red segmentada en VLANs con ACLs; base de datos MySQL.
`Ubuntu Server` `Bash` `Cisco Packet Tracer` `MySQL` `XML/XSLT`

**[n8n Automation Lab](https://github.com/ndoreste/n8n-automation-lab)**
Workflows que tengo activos en mi instancia de n8n, exportados sin credenciales: briefing diario de IA con LLM, traductor técnico de laboratorios de ciberseguridad vía webhook y borradores con aprobación humana en Telegram.
`n8n` `OpenRouter` `Telegram Bot API` `Webhooks`

**[noSQL Movies API](https://github.com/ndoreste/nosql-movies-api)**
API REST de películas, cines y series con arquitectura por capas, almacenamiento intercambiable (MongoDB / memoria), tests automatizados y colección Postman.
`Node.js` `Express` `MongoDB` `Mongoose` `node:test`

**[Attendance Record Signature App](https://github.com/ndoreste/attendance-record-signature-app)**
Registro de asistencia con firma digital y exportación a Excel.
`Node.js` `Express` `MongoDB` `ExcelJS`

**[Interactive Test Platform](https://github.com/ndoreste/interactive-test-platform)** · [demo](https://ndoreste.github.io/interactive-test-platform/)
La herramienta con la que preparo los exámenes de ASIR: tests por módulo (redes, sistemas, bases de datos, hardware, nube), flashcards y simulacros.
`HTML` `CSS` `JavaScript`
